## ✨ 구현 기능 목록

### 1. 입력 처리

- [ ] `Console.readLineAsync()`를 사용해 문자열 입력을 받는다.
- [ ] 입력값이 비어 있는 경우(`""`) `0`을 반환한다.
- [ ] 입력 문자열에서 커스텀 구분자를 인식한다.
  - 형식: `"//[구분자]\n[숫자들]"`

### 2. 문자열 파싱

- [ ] 기본 구분자 `,`(쉼표), `:`(콜론)을 기준으로 문자열을 분리한다.
- [ ] 커스텀 구분자가 존재할 경우 해당 구분자로 분리한다.
- [ ] 분리된 문자열을 숫자 배열로 변환한다.
- [ ] 변환 과정에서 숫자가 아닌 값이 존재하면 예외를 발생시킨다.

### 3. 계산 로직

- [ ] 숫자 배열의 합을 구한다.
- [ ] 음수 또는 잘못된 값이 포함된 경우 `[ERROR]`로 시작하는 메시지와 함께 `Error`를 발생시킨다.

### 4. 출력

- [ ] 계산된 합계를 `"결과 : X"` 형식으로 출력한다.
- [ ] 출력 시 `Console.print()`를 사용한다.

### 5. 예외 처리

- [ ] 입력 형식이 잘못되면 프로그램을 종료하지 않고 예외를 던진다.
- [ ] `[ERROR]` 메시지로 시작하는 오류 문구를 출력한다.
- [ ] `process.exit()`는 사용하지 않는다.

### 6. 실행 구조

- [ ] `App.js`의 `run()`에서 프로그램이 시작된다.
- [ ] 주요 기능은 모듈화한다.
  - 예: `InputHandler`, `StringParser`, `Calculator`, `OutputView` 등

## 💬 커밋 메시지 컨벤션 (AngularJS 스타일)

| 유형(Type) | 설명                                   |
| ---------- | -------------------------------------- |
| feat       | 새로운 기능 추가                       |
| fix        | 버그 수정                              |
| refactor   | 코드 리팩터링 (기능 변경 없음)         |
| test       | 테스트 코드 추가/수정                  |
| docs       | 문서 수정 (README 등)                  |
| style      | 코드 스타일 변경 (포맷팅, 세미콜론 등) |
| chore      | 빌드 설정, 패키지 관련 작업 등 기타    |
